# ADR-006: Data sources and network posture

Status: accepted · 2026-07-08
Deciders: Fable (design agent), conservative defaults; endpoints verified live

## Context

Signals require external data. Sources differ in auth requirements,
stability, and trustworthiness. A security tool's own network behavior is
part of its threat surface. Research: [research/data-sources.md](../research/data-sources.md).

## Decision

1. **Fixed host allowlist** (exactly seven, HTTPS-only, enforced in
   `infra/http.ts` as code, not config): `registry.npmjs.org`,
   `api.npmjs.org`, `pypi.org`, `pypistats.org`, `api.deps.dev`,
   `api.osv.dev`, `api.github.com`. Adding a host requires updating this ADR.
2. **No API keys required** for any primary signal. The only credential ever
   read is `VETLOCK_GITHUB_TOKEN` / `GITHUB_TOKEN` (optional, env-only,
   never persisted or logged); without it, GitHub-derived signals degrade to
   `unavailable(rate-limited)` and stars/scorecard still arrive via deps.dev.
3. **Registry of record first**: npm/PyPI registries are authoritative for
   package facts; deps.dev, OSV, GitHub, and download-stat APIs are
   enrichment and may be unavailable without failing the run (fail-open
   execution, fail-closed reporting).
4. **Caching**: file cache with per-source TTLs (registry 1 h; downloads &
   deps.dev 24 h; OSV & GitHub 1 h) + ETag revalidation; `--offline` serves
   any-age cache and marks misses `unavailable(offline)`.
5. **Typosquat reference data is bundled, not fetched at runtime**
   (`data/top-packages/*.json`, generated by a maintenance script from
   hugovk/top-pypi-packages and `npm-high-impact`) — keeps runtime
   deterministic and offline-capable.
6. **No telemetry, no update checks, no phone-home** of any kind.

## Consequences

- pypistats (community-run) is the weakest link → popularity for PyPI is
  best-effort by design (known unknown U2).
- Bundled top-package lists age between releases; acceptable (typosquats
  target durable popular names) and refreshed per release.
- `verify` needs no network at all — CI gate works in air-gapped runners.
